# Проект по изучению работы драйверов на современных версиях ядра Linux

Есть два основных материала по разработке драйверов устройств:
[Linux Device Drivers](https://lwn.net/Kernel/LDD3/) - далее LDD3 и [The Linux Kernel Module Programming Guide](https://sysprog21.github.io/lkmpg/) - далее KLMPG

LDD3 написан сравнительно давно и более обширен. KLMPG современнее и легче в чтении.

Поэтому можно начинать с KLMPG и переходить к LDD3. При этом некоторые модули совсем перестали совпадать с описанием в LDD3. Поэтому некоторые вещи, как block device можно взять из сторонних источников [Block Device Drivers Linux Kernel Labs](https://linux-kernel-labs.github.io/refs/heads/master/labs/block_device_drivers.html) и [Linux Kernel 5.0 — пишем Simple Block Device под blk-mq](https://habr.com/ru/companies/veeam/articles/446148/).
