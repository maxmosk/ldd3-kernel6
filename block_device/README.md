Собрать блочное устройство по книге LDD3 не представляется возможным, поскольку многие вещи были изменены начиная с ядра версии 5.
Примеры блочных устройств также отсутствуют в книге KLMPG.

Аналогом для простого блочного устройства является статья: https://prog.world/linux-kernel-5-0-we-write-simple-block-device-under-blk-mq/
Перевод статьи: https://habr.com/ru/companies/veeam/articles/446148/

В отличии от приведенных в статье примеров, данный пример работает только на современных ядрах.

Сборка проекта:

0) Убедиться, что на машине установлена kconfig. Если не установлена, то установить sudo apt-get install kconfig-frontends
1) Из директории блочного устройства вызвать kconfig-mconf Kconfig. В открывшемся меню выбрать желаемые опции и сохранить (не изменяем имя выходного файла, ожидается, что его имя .config).
2) Запускаем make.
