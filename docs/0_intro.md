Общие рекомендации: 
Несмотря на то, что основной упор идет на изучение LDD3, все же, для начала, хочется порекомендовать использовать более “свежий” источник KLMPG, там описано несколько меньше типов модулей и возможностей работы, но все примеры более подробные и уже применимы к ядрам версии 5 и выше. К тому же, KLMPG более подойдет новичкам, которые никогда не писали модули для ядра, LDD3 рассчитан на то, что читатель уже знаком с некоторыми концепциями и ему необходимо создавать свой модуль опираясь на уже имеющийся опыт.

Если использовать vscode в качестве среды разработки, то для корректного отображения заголовочных файлов рекомендуется поставить расширение для C/C++, которое от Microsoft, и в Command palette найти и выбрать C/C++: Edit Configurations (JSON). В конфигурационном файле прописать (указав свою версию):
{
    "configurations": [
        {
            "name": "Linux",
            "includePath": [
                "${workspaceFolder}/**",
                "/lib/modules/6.5.0-26-generic/build/include",
                "/lib/modules/6.5.0-26-generic/build/arch/x86/include",
                "/usr/src/linux-headers-6.5.0-26-generic/arch/x86/include/generated/"
            ],
            "defines": [
                "__GNUC__",
                "__KERNEL__",
                "MODULE"
            ],
            "compilerPath": "/usr/bin/gcc",
            "cStandard": "c17",
            "cppStandard": "gnu++17",
            "intelliSenseMode": "linux-gcc-x64"
        }
    ],
    "version": 4
}
