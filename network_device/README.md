Сборка проекта:

0) Убедиться, что на машине установлена kconfig. Если не установлена, то установить sudo apt-get install kconfig-frontends
1) Из директории блочного устройства вызвать kconfig-mconf Kconfig. В открывшемся меню выбрать желаемые опции или оставить значения по умолчанию и сохранить (не изменяем имя выходного файла, ожидается, что его имя .config).
2) Запускаем make.
